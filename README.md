# Generative AI Research Project

This repository contains research materials for the study:

**Using Generative AI Tools - Boon or Bane**

## Repository Structure

- `Literature_Review/` – journal articles, conference papers, books and other literature.
- `Quantitative_Analysis/` – survey data, analysis scripts and quantitative reports.
- `Qualitative_Analysis/` – interview transcripts, protocols, consent forms, reports and visualisations.
- `Drafts_and_Reports/` – research proposals, conference papers and final reports.
- `Additional_Materials/` – information sheets, photographs and other media.

## Version Control

Git is used to track changes to project files. Contributors should use meaningful commit messages describing the changes made.

## Contributing

1. Pull the latest version of the repository.
2. Create a branch for your changes.
3. Make and test your changes.
4. Commit using a descriptive commit message.
5. Push the branch to GitHub.
6. Create a pull request for review.
